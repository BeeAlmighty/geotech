WORK SCREENSHOTS — drop client website screenshots here.

Henna Girl (hennagirl.shop):
  Save the photo/screenshot in THIS folder as exactly:
      henna-girl.jpg
  It then appears automatically at the top of the Henna Girl card on the
  homepage and /work. (Path referenced in src/lib/projects.ts -> image.)

Recommended:
  • Aspect ratio ~4:3 (e.g. 1200 x 900) or 16:9 (1280 x 720)
  • JPG or WebP, under ~300 KB (compress at squoosh.app or tinypng.com)
  • Show the real site / a clean hero crop — no browser chrome if possible

To add an image to another project, drop the file here and set its `image`
field in src/lib/projects.ts, e.g.  image: "/work/decor-adorne.jpg".

If a file is missing or misnamed, the card shows a tidy "Photo coming soon"
plate instead of a broken image — so nothing breaks.
